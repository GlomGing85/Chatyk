# 💬 Чатик — простий месенджер для Android

Месенджер без реєстрації: придумав код кімнати, поділився з другом — і спілкуєтесь.
Повідомлення приходять у реальному часі через **Firebase Realtime Database**.

> 🛠 **Важливо**: весь цей проєкт **вже перевірено** — він збирається в APK.
> Тобі потрібен лише телефон: жодного комп'ютера!

---

## 📱 Що вміє додаток

- Вхід без реєстрації (анонімно, одним натисканням)
- Кімнати за кодовим словом: однаковий код = спільна переписка
- Повідомлення в реальному часі (як у справжньому месенджері)
- Статус «у мережі» для учасників кімнати
- Темна тема, автоматичний скрол до нових повідомлень
- Випадковий кумедний нікнейм (можна змінити)

## 📥 Спочатку: скачай проєкт

1. Завантаж архів **`messenger-project.zip`** з робочої області (workspace) на свій телефон.
2. Розпакуй його (на Android це вміє «Файли» від Google: тримаєш палець на zip → «Розпакувати»).
3. Усередині буде папка `messenger/` — саме її файли ми й завантажимо на GitHub.

## 👣 Крок 1. GitHub-репозиторій

1. Відкрий [github.com](https://github.com) у браузері телефону і створи акаунт (безкоштовно), якщо його ще нема.
2. Натисни **New repository** (або значок `+` праворуч угорі → New repository).
3. Назва: `chatyk` (можна будь-яку).
4. **Public** — обов'язково (для приватних репозиторіїв безкоштовних хвилин збірки менше; публічний — необмежено).
5. **НЕ** відмічай «Add a README file» — репозиторій має бути порожнім.
6. Натисни **Create repository**.

> 🔑 Порада: запам'ятай логін GitHub — він стане частиною адреси твого репозиторію:
> `https://github.com/ТВІЙ_ЛОГІН/chatyk`

## 🔥 Крок 2. Firebase (безкоштовний «сервер»)

Месенджеру потрібна спільна база даних, куди обидва телефони пишуть і звідки читають. Це і є Firebase.

1. Відкрий [console.firebase.google.com](https://console.firebase.google.com) у браузері телефону.
2. Увійди зі своїм Google-акаунтом → **Створити проєкт**.
   - Назва: `chatyk` (будь-яка)
   - Google Analytics: можна **вимкнути** (Toggle вимкнути) — так швидше.
3. Після створення проєкту натисни значок **Android** (`+` для додатку):
   - **Android package name:** `com.example.messenger` — точнісінько так, з крапками!
   - Решта полів — необов'язкові.
   - **Register app**.
4. З'явиться кнопка **Download google-services.json** — завантаж цей файл на телефон (запам'ятай, куди він зберігся). Він нам знадобиться на кроці 3.
5. Тепер увімкнемо спілкування. У лівому меню консолі:
   - **Build → Realtime Database** → **Create database**.
   - Регіон: обери **`europe-west1`** (Бельгія) — ближче до України, швидше.
   - Режим безпеки: **Start in production mode** (правила ми зараз напишемо самі).
6. У вкладці **Rules** заміни правила на ці і натисни **Publish**:

   ```json
   {
     "rules": {
       ".read": "auth != null",
       ".write": "auth != null"
     }
   }
   ```

   Це означає: читати й писати можуть лише увійшовші користувачі (у нас — анонімні).
7. Включимо анонімний вхід. У лівому меню:
   - **Build → Authentication** → **Get started** → вкладка **Sign-in method**.
   - Знайди **Anonymous** → увімкни (Enable) → **Save**.

Готово! Firebase-частина зроблена. Далі ми покладемо `google-services.json` у проєкт — і додаток знатиме, з якою базою працювати.

## 📤 Крок 3. Завантаж код на GitHub

Є два варіанти. Найзручніший — через **github.dev** (це VS Code прямо в браузері).

### Варіант А: github.dev (рекомендую)

1. Відкрий свій порожній репозиторій (посилання з кроку 1) у браузері телефону.
2. У адресному рядку браузера заміни `github.com` на `github.dev` і натисни Enter.
   *(Або: на сторінці репозиторію натисни клавішу `.` — спрацює так само.)*
3. Відкриється онлайн-редактор коду. Зліва — список файлів (Explorer).
4. Наведи на Explorer і натисни значок **Upload Files...** (це два файли зі стрілкою вгору).
   - Обери вміст папки `messenger/` **разом з папками**: `app/`, `.github/`, `gradle/` тощо.
   - Якщо файл-пікер не дає обрати цілу папку — завантаж папку за папкою: `app/`, `.github/`, `gradle/`, потім поодинокі файли (gradlew, build.gradle.kts…).
5. Тепер додай `google-services.json` (той, що завантажив на кроці 2) **у папку `app/`**: Explorer → `app` → значок Upload → обрати файл.
6. Після завантаження всіх файлів унизу з'явиться поле для опису коміту → натисни галочку **Commit** (або `✓` угорі праворуч).
7. Коли закомітиш — github.dev сам запитає, чи відкрити сторінку репозиторію. Погоджуйся.

### Варіант Б: звичайний GitHub

1. На сторінці репозиторію натисни **Add file → Upload files**.
2. Перетягни або обери файли. GitHub не розуміє папок із телефону, тому завантажуй групами:
   - `app/src/main/java/com/example/messenger/` — тут уважно: спершу створи папки кнопкою «папка»/назва шляху, або завантажуй по файлу.
   - Це повільніше, але теж працює.
3. Не забудь `google-services.json` у папку `app/`.
4. **Commit changes** — і код залито в гілку `main`.

> ✅ Як перевірити, що все на місці: на головній сторінці репозиторію мають бути папки `app`, `.github`, `gradle` і файл `build.gradle.kts`, а всередині `app` — `google-services.json`.

## ⚙️ Крок 4. Збірка APK у хмарі (GitHub Actions)

1. Відкрий репозиторій → вкладка **Actions**.
2. Ти побачиш запуск із назвою **«Збірка APK»** — він стартував автоматично після заливання коду. Зайди в нього.
3. Зачекай ~5–10 хвилин (перша збірка найдовша). Коли всі кроки будуть з **зеленими галочками** ✅ — готово.
4. Прокрути сторінку вниз до блоку **Artifacts** → натисни **`chatyk-apk`** — завантажиться zip-архів.
5. Розпакуй його — усередині буде **`app-debug.apk`**. Це і є твій додаток!

> 🔁 Хочеш перебудувати пізніше: **Actions → Збірка APK → Run workflow**.

---

## 📲 Крок 5. Встановлення та перший чат 🎉

1. Зайди на **перший телефон**, відкрий файл `app-debug.apk` (через «Файли»).
2. Android попередить про «невідомі джерела» → дозволь установку (Settings → дозволити цей додаток / або просто натисни «Встановити все одно»).
3. Встанови так само на **другий телефон** (передай APK через будь-який месенджер, Bluetooth або хмару).
4. Відкрий «Чатик» на обох телефонах:
   - залиш кумедний нікнейм або впиши свій;
   - впиши **один і той самий код кімнати** (наприклад `kvity-2026`);
   - «Увійти до кімнати».
5. Пишіть одне одному! Повідомлення з'являються миттєво, а вгорі видно, хто в мережі.

## 🧠 Як це працює (коротко)

| Файл | Що робить |
|------|-----------|
| `MainActivity.kt` | Точка входу: показує екран входу або чат + тему додатку |
| `LoginScreen.kt` | Нікнейм + код кімнати, вхід |
| `ChatScreen.kt` | Стрічка повідомлень, поле вводу, статус «онлайн» |
| `ChatViewModel.kt` | Уся логіка: підключення до Firebase, відправка, слухачі змін |
| `build.gradle.kts` | Залежності (Compose, Firebase) |
| `.github/workflows/build.yml` | «Рецепт» збірки в GitHub Actions |

Дані зберігаються в Firebase як дерево:

```
rooms/
└── kvity-2026/          ← код кімнати
    ├── messages/        ← повідомлення (автор, ім'я, текст, час)
    └── presence/        ← хто онлайн (ім'я + lastSeen)
```

Слухачі в `ChatViewModel` автоматично оновлюють екран, коли в базі з'являється щось нове — тому чат «живий».

## ❓ Що може піти не так (Troubleshooting)

| Симптом | Причина | Рішення |
|---------|---------|---------|
| Збірка падає: «google-services.json is missing» | Не поклав файл | Додай `google-services.json` у папку `app/` і закоміть |
| Збірка падає: «File google-services.json is missing» в іншому місці | Файл не в тій папці | Він має бути саме в `app/google-services.json` |
| У додатку помилка «Permission denied» | Правила БД не опубліковані | Крок 2, пункт 6: встав правила і **Publish** |
| «Анонімний вхід не працює» | Не увімкнено Authentication → Anonymous | Крок 2, пункт 7 |
| Не бачу Artifacts | Не ввійшов в GitHub | Зайди під своїм акаунтом |
| Друг не бачить повідомлення | Різні коди кімнат або регіон бази не збігається | Код має бути однаковим, символ у символ |

> ⚠️ Це навчальний проєкт: повідомлення не шифруються, і будь-хто, хто знає код кімнати, може туди зайти. Для переписок з друзями — ок, для секретів — ні.
