# 💬 Чатик — простий месенджер для Android

Месенджер без реєстрації: придумав код кімнати, поділився з другом — і спілкуєтесь.
Повідомлення приходять у реальному часі через **Firebase Realtime Database**.

> 🛠 **Важливо**: весь цей проєкт **вже перевірено** — він збирається в APK.
> потрібен лише телефон: жодного комп'ютера!

> ℹ️ **Інфо:** Цей проєкт все ще `розробляється` і **може містити помилки!**
> 
> повідомлення не шифруються, і будь-хто, хто знає код кімнати, може туди зайти. **(не рекомендується надсилати будь-які секрети!!)**

## 📱 Що вміє додаток

- Вхід без реєстрації (анонімно, одним натисканням)
- Кімнати за кодовим словом: однаковий код = спільна переписка
- Повідомлення в реальному часі (як у справжньому месенджері)
- Статус «у мережі» для учасників кімнати
- Реакції-емодзі на повідомлення (довгий тап по повідомленню)
- Кнопка «Поділитися» кодом кімнати з другом
- Темна тема, автоматичний скрол до нових повідомлень
- Випадковий кумедний нікнейм (можна змінити)

## 📲 Встановлення та перший чат 🎉

1. Завантажте останню версію із [Releases](https://github.com/GlomGing85/Chatyk/releases/)
2. після завантаження: відкрий файл `app-release.apk` (через «Файли»).
3. Android попередить про «невідомі джерела» → дозволь установку (Settings → дозволити цей додаток / або просто натисни «Встановити все одно»).
4. Встанови так само на **Телефон друга** (передай APK через будь-який месенджер, Bluetooth або хмару).
5. Відкрий «Чатик» на обох телефонах:
   - залиш кумедний нікнейм або впиши свій;
   - впиши **один і той самий код кімнати** (наприклад `kvity-2026`);
   - «Увійти до кімнати».
6. Пишіть одне одному! Повідомлення з'являються миттєво, а вгорі видно, хто в мережі.

> 🔄 **Оновлюєшся з 0.0.2 або 0.0.3-Alpha1?** Один раз видали стару версію, а потім встанови нову.
> Старі збірки були підписані *тимчасовими* ключами, тому Android не ставить нову версію поверх
> («Додаток не встановлено»). Починаючи з 0.0.3 оновлення ставляться поверх, як і має бути.

## 🧠 Як це працює (коротко)

| Файл | Що робить |
|------|-----------|
| `MainActivity.kt` | Точка входу: показує екран входу або чат + тему додатку |
| `LoginScreen.kt` | Нікнейм + код кімнати, вхід |
| `ChatScreen.kt` | Стрічка повідомлень, поле вводу, статус «онлайн» |
| `ChatViewModel.kt` | Уся логіка: підключення до Firebase, відправка, слухачі змін |
| `build.gradle.kts` | Залежності (Compose, Firebase) |
| `.github/workflows/build.yml` | «Рецепт» збірки в GitHub Actions |
| `database.rules.json` | Правила безпеки бази (хто що може читати й писати) |
| `scripts/setup-signing.sh` | Одноразове налаштування постійного ключа підпису (Termux) |
| `CHANGELOG.md` | Історія змін за версіями |

Дані зберігаються в Firebase як дерево:

```
rooms/
└── kvity-2026/          ← код кімнати
    ├── messages/        ← повідомлення (автор, ім'я, текст, час, реакції)
    └── presence/        ← хто онлайн (ім'я + lastSeen)
```

Слухачі в `ChatViewModel` автоматично оновлюють екран, коли в базі з'являється щось нове — тому чат «живий».

>
> 🔐 Завдяки правилам бази ([`database.rules.json`](./database.rules.json)) список кімнат нікому не видно, тож **код кімнати працює як пароль**. Обирай код, який важко вгадати: `kvity-2026-lys-817` набагато краще, ніж `test`.

## 🎨 Як змінити додаток
